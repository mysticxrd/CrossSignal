# Data compatibility for b01-hiring-showcase-v1 — pending review

The proposed change is sampling and initial-showcase scope. It changes no
accepted data bytes, causal generator, public/private split, observation cutoff,
evidence IDs, common schema, task, rubric or semantic judgment.

All five public incident-data-v2 packages remain frozen. Host bindRun creates
fresh synthetic identities per method and preserves evidence facts. The two
development cases and three frozen-transfer cases retain their original roles;
no prompt/rule tuning on transfer feedback. Authors already know the families,
so these are transfer checks rather than pristine research holdouts.

Each method uses benchmark-finding-v1; epistemic abstention differs from failure.
The model receives the allowed evidence universe eagerly or through the three
existing scoped tools. Evaluator labels/truth and blinded judgments remain in
separate evaluator contexts. Readable Case projections do not return old answers
to the model. Structural output/citation membership does not prove semantic support.

per Case/method. Twenty initial repeats and 15 changed-investigator records are
deferred; their variability/improvement claims cannot be made. The five existing
cases are not 15 independent incidents. The same rubric dimensions and all
scheduled failures/abstentions remain in the report denominator. No threshold
or expected answer changes to accommodate provider failure or a weak result.

The original token/context/tool/timeout/concurrency/retry limits and $0 account
conditions are unchanged. The accepted SIWC amendment and pending compatibility
gate are preserved as unrelated, unselected history.

Prepared plan identities are proposals, not executed investigations. Acceptance
of this exact compatibility record is part of the scope overlay; it does not
accept/rewrite the existing Data gate or provide generation/runtime authority.
Current accepted hashes are recorded in PRESERVATION_BEFORE.json. The larger
B01 milestone, repeated study, experiment and intervention remain incomplete.
