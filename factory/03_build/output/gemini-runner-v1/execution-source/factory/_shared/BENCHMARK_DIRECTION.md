# API behavioral benchmark direction

The September 29 Notion decision selects A01 model investigation → five causally
different incidents → rules/single-shot/tool-model comparisons → failure analysis
→ one measured improvement. The September 30 user correction removes local
models and selects hosted AI APIs. The current charter is
`docs/api-benchmark-charter.md`; reconciliation and API execution boundaries
are separate declared Stage 01 inputs. Provider/model and spend remain open.

Reuse the bounded tools, private simulator, separate grader, recorder and exact
authority checks. Preserve the scripted A01 baseline as a scoped mechanics
reference. No framework, connector expansion or upfront 100-case program.
Five cases are initial comparison evidence, not robust accuracy/calibration.

Define expected observable-evidence judgments before scoring. Isolate private
truth, authored labels, old grader reports and world state from model/tools/API
inputs. Same evidence universe across all baselines; record eager versus query
presentation. Preserve failed runs and fresh variation versus transcript replay.

Record diagnosis, citations/support, unsupported claims, contradiction analysis
and active search separately, abstention, recommendation, tool efficiency,
latency, usage and charges where available. Freeze provider/model/configuration,
prompts, data, rubric and experiments. Improve one thing; a negative result is valid.

Keep tenant isolation, exact payload/context/policy approval, Global Pause,
append-only Case history, one-time execution, indeterminate states, old fixtures
and the excluded trial receipt. No LIVE/product hosted writes. No paid calls
until explicitly permitted by a user budget; API access is not spending approval.

One exact human-approved A01 simulated intervention is part of this milestone;
stage gates never authorize it. All results say SIMULATED and cannot establish
actual payments, real Mobile Safari verification or business recovery. Those
real-check paths remain deferred. Do not make governance expansion the project.
